# v3 SB0 — offline retained Slot0 command experiment

Status: **self-checked**, not a device candidate. No device access, new image,
hardware qualification, authorization or independent verification.

## Admission and command

`tests/NuwaSb0Experiment.h` is compiled only by the explicit `--sb0` fixture
build (`NUWA_SB0_HOST_FIXTURE=1`); it has no boot hook. Its one-shot trial
requires the separate explicit mock argument, injected window ownership and
backup/restoration assertions, and a nonzero synthetic seed matching the
expected backup seed. It does not fabricate `ColdStartEvidence`,
`ReinitPermit`, or proven FUA. Ordinary mode 2, tested even with the old
write build opt-in and both absent/present `nuwa-data-write=1`, submits no
commands. Production remains `Provider<CandidatePort, false>`.

Under the existing fixture host lock, the trial checks LU0/4096-byte geometry
and fixed root bytes, window and reserve; validates live simulated primary
and backup GPT headers/tables against an independent synthetic identity; then
reads window offsets `0..769` and the legacy anchor at `2097857` (legacy
offset `640` is within `0..769`). That is four GPT reads and 771 distinct
window reads: SB0/SB1, all 256 map pages, all 512 ring pages and both historic
anchors. Nonzero content or a read error stops at the first affected page
with zero writes. Data banks outside this set are not scanned. Only the
synthetic backup/ownership assertions cover the rest of the window.

After all 775 reads, `initialSuperblock` serializes the empty v3 SB0 with the
synthetic seed. `CandidatePort` → `RetainedWritePort` → staged
`CombinedRead::issue` runs the real encoder, post-prepare guard, polling and
response attribution with simulated MMIO/medium. The GOOD fixture verifies
all CDB bytes, LU0, LBA `57393401`, 4096 B, FUA, PRDT, all payload bytes, and
exactly one DB0 write submission. The trial has no `writeRun`/checkpoint,
block device publication, public sync, retry, repair, or teardown path.

`tests/test-nuwa-dualbank.cpp` compares its full 4096 bytes with the first
checkpoint generated by the overlay and an independent transcription of the
pre-extraction format. The shared serializer preserves the old checkpoint
flow; only the independent overlay regression tests invoke it.

## Results

| Scenario | Observed in fixture |
| --- | --- |
| Host flag off/arg only, enabled/no arg, missing owner or backup, altered LU/block/capacity/window/reserve/root/seed | 0 reads, 0 writes |
| Bad primary or backup CRC, matching CRCs but mismatched tables | 4 reads, 0 writes |
| Existing SB0, damaged map, last ring page, legacy anchor, metadata read error | 5/158/774/775/645 reads respectively, 0 writes |
| Guard lost after staging | 775 reads, one write preparation, 0 write DB0s, terminal |
| Wrong tag/LUN, short transfer, attributed command error, timeout/late GOOD | 775 reads, one write DB0 each; terminal, no root/Data or DMA/MMIO reuse |
| GOOD then simulated loss, torn prefix with timeout, reported error with all bytes already written | One write DB0 each; persisted content is empty, first 2048 bytes, or full SB0 respectively; no repair/retry |
| GOOD | One write DB0 after 775 reads; full expected SB0 in simulated media |

Failed metadata reads also isolate the fixture host. After write faults,
the ordinary root block request and Data reopen/read/write/sync paths are
checked for refusal; late GOOD/DB=0 cannot reclaim the old Slot0. Ordinary
denial for bad input or nonzero metadata is not a transport fault. A GOOD
response is not durable proof, and an error is not proof of unchanged media.

## Staged and final-link audit

The audit compares staged transport files against fixture copies (the
absolute device-header include root is the only substitution), and compares
unchanged gate/transport files with the original NEON tree. The explicit
host link contains the trial; the default host link and the **existing**
NEON production objects/native/final kernel do not. Disassembly of the old
final kernel confirms that store write/sync and log/export write/sync do not
submit any command and return zero. The encoder refactor was tested in the
host builds, not rebuilt into the historical production kernel.

Existing r2, r3, and the outer FAT's `EFI/UniXNU/Payloads/kernel.macho` are
byte-identical. The outer's direct vendor-ramdisk slice also matches both
stored FAT copies byte-for-byte. No new package was built or released.
