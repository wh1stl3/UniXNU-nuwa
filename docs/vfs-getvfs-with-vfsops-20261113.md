# VFS bridge: bounded host implementation

The 8796 device patch adds fsid plus `mnt_op` pointer lookup, declaration and export-list entry. It adds no reference, busy operation, unmount filter or locking change. The bridge only addresses a missing symbol; it does not discover a root device. Parent reports the latest device milestone as pthread returned and `IOFindBSDRoot` panic 908; PMGR is not end-to-end demonstrated. Recovery is awaiting notification, not declared complete.

Self-checked: WSL `/home/wh1stl3/.local/bin/python3.11 scripts/build-vfs-bridge-object.py --out /mnt/d/Code/PortingiOS/nuwa/UniXNU-nuwa/out/vfs-bridge-object-20261113-r3 --source-copy /root/nuwa-vfs-bridge-20261113-r3` exited 0. Full command arguments and exits for patch, native compile, nm, host test compile and run are in `out/vfs-bridge-object-20261113-r3/commands.json`. Native ARM64 object is 516168 bytes, SHA256 `29b722f3625ba9b93da8698d56de7eb31918afce806c49c0d4c015334c47a076`; patch SHA256 `19fcb0a37a806db0a537cd059d604d7e8b1924379dea30bd0f9c9d8309311cf9`. `/usr/bin/llvm-nm` reports defined global `T _vfs_getvfs_with_vfsops`; the isolated header declaration and BSDKernel.exports entry are checked. Compilation uses the isolated source copy with existing generated build headers.

The host test compiles the actual two function bodies extracted from the patched 8796 file, with a minimal synthetic mount list and instrumented lock/reference primitives; it is not a kernel concurrency test. Two matches, ops mismatch, either fsid word mismatch and an empty list returned expected values, each with one lock, one unlock and no iterref. The script asserts that removing the bridge reproduces the entire original `vfs_subr.c` byte-for-byte, so the original lookup helper is unchanged. Actual concurrent unmount and mount lifetime are not tested. r1's missing nm path was corrected to the installed `/usr/bin/llvm-nm`; the earlier `/usr/bin/python3` record check lacked tomllib and is superseded by Python 3.11.

This is object and source-contract evidence, not a final kernel export or APFS prelink/import/ops relocation test; these remain for the next stage. No prelink, outer image, executor or device operation was performed. Independent verifier rerun remains pending.
