# FDR exit slot — host self-checked

The r35l display ON renderer records exact `IOMFB_FDR_Loader` exit names
independently of the four-slot abnormal exit ring. A relaxed atomic 64-bit
store before the existing try-lock packs seconds in bits 63:32, raw wait
status in 31:16, zero in 15:8 and signal in 7:0; the draw path takes one
relaxed load. Row 10 displays `FDR <t>s st=<status> sig=<sig>` (decimal) or
`FDR no exit seen`. It replaces a stage-history/UI-trace row, not EX1–EX4,
X1–X3, DSP or the existing conditional stg row. Row 10 is outside the
panic-safe band. Status is raw wait status, not the decoded exit code.

No exit seen does not prove launch, liveness, connection or first frame.
The zero encoding also collides with a successful exit in second zero.
An observed exit gives status and signal, but its connection meaning needs
independent loader semantics. Concurrent writers are atomic but latest means
last store, not necessarily latest timestamp. The existing hook supplies
`p->p_name`; runtime name and capture remain unverified. No `inPlane` check.
329 guard and ON boot arguments remain unchanged.
